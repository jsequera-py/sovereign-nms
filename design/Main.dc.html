Sovereign NMS · visual language 01

Trust primitives

Every claim the interface renders carries three attributes: how it was established, how strongly, and how long ago. They ride on independent visual channels so any combination stays readable — and so no number can appear without its age.

Fidelity — line construction

What we know about the endpoints. Never colour: colour is reserved for state.

Interface fidelity — suppression-capable

Terminals close on both nodes and both ports are named. The line lands somewhere specific, which is what makes the link usable for alert suppression.

Device fidelity — adjacency only

Open terminals and a gap at each end: we know the boxes are adjacent, not which ports. RouterOS 6.49 returns lldpRemLocalPortNum = 0, so this is the honest render, not a degraded one. The dashed node is a neighbour outside the inventory — observed, never polled.

Freshness — stroke pattern

Computed on read from max(evidence age). W = 30 min evidence window. Three distinct dash patterns — solid, long-dash, fine-dash — so the state survives greyscale and colour-blindness.

FRESH · age ≤ W
AGING · W < age ≤ 2W
STALE · age > 2W

A stale link keeps its last confidence and loses its authority. The number is never decayed — 0.80 was true when it was measured, and inventing 0.42 to represent uncertainty fabricates a measurement that was never taken.
